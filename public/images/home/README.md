# BAGATI homepage photography

The default carousel's technology slide uses original, unbranded BAGATI artwork at `hero-tech-campaign.svg`. It is drawn for this project and has no external image source or third-party image license. The other photographic category slides are illustrative, licensed mood imagery; they do not represent current marketplace inventory.

## Photography brief for future replacements

Supply only self-made images or images with a license that permits commercial use in an e-commerce storefront. Keep the source URL, creator, and license with this README before adding an asset.

- Neutral still-life or editorial lifestyle scenes, art-directed for a calm forest-green, cream, and ivory storefront.
- No logos, recognizable brand products, copied marketplace imagery, or claims that a photo depicts live BAGATI stock.
- Compose each scene to work at both 16:9 and 4:5 crops, with clear breathing room for overlaid type.
- Deliver WebP files under 200 KB where visual quality allows; retain sharp detail and natural color.
- Use meaningful Azerbaijani alt text when the image conveys content; use empty alt text for purely decorative imagery.
